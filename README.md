# 🎱 lotoMironBot

> Telegram-бот для проведения игр в **«Русское лото»** с управлением играми, билетами, участниками и розыгрышем прямо в Telegram.

**lotoMironBot** — это полноценная игровая система для проведения лото-розыгрышей в Telegram-группах.

Бот хранит игровые билеты, управляет участниками, автоматически проводит розыгрыш чисел и определяет победителя по заданным правилам.

---

## ✨ Возможности

### 🎟️ Игровые билеты

- Поддержка заранее подготовленных билетов.
- Один игрок может получить несколько билетов.
- Один и тот же билет невозможно выдать нескольким игрокам.
- Хранение билетов и их чисел в базе данных.
- Возможность забрать билет обратно.
- Отображение свободных и занятых билетов.

### 🎲 Игровой процесс

- Случайная генерация чисел от **1 до 100**.
- Одно число не может выпасть повторно.
- После каждого хода бот проверяет все активные билеты.
- Выпавшие числа автоматически удаляются из оставшихся чисел билета.
- Когда на билете не остаётся чисел — игрок объявляется победителем.
- Правила победы могут настраиваться для каждой игры.

### 👑 Управление играми

Администраторы могут:

- создавать игры;
- выбирать группу, в которой проводится игра;
- настраивать правила победы;
- управлять билетами;
- запускать и завершать розыгрыш;
- просматривать состояние игры;
- изменять параметры активной игры.

### 🛡️ Система ролей

В боте предусмотрена ролевая модель с разграничением доступа.

Основные уровни:

- **Owner** — полный контроль над ботом;
- **Admin** — управление играми;
- обычные пользователи — участие в играх.

Owner дополнительно может:

- добавлять и удалять администраторов;
- изменять правила игры;
- управлять настройками бота;
- контролировать игровые группы.

## 🗄️ Хранение данных

Проект использует **PostgreSQL** как основную базу данных.

В базе хранятся:

- пользователи;
- роли;
- игры;
- игровые группы;
- билеты;
- числа билетов;
- состояние розыгрыша;
- настройки игры;
- связь игроков с билетами.

Для временных данных и FSM используется **Redis**.

## 🚀 Запуск

### Требования

Перед запуском необходимо установить:

- Go 1.24+
- Docker
- Docker Compose

### 1. Клонирование

```bash
git clone <repository-url>
cd lotoMironBot
```

### 2. Настройка окружения

Создайте `.env`:

```env
BOT_TOKEN=your_telegram_bot_token

POSTGRES_DB=loto
POSTGRES_USER=loto
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432

REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
```

### 3. Запуск инфраструктуры

```bash
docker compose up -d
```

### 4. Запуск бота

```bash
go run ./cmd/app
```

## 🎮 Концепция игры

В начале игры администратор формирует игровую сессию и определяет её правила.

Игроки получают билеты, после чего администратор запускает розыгрыш.

Бот начинает последовательно выбирать случайные числа:

```text
42 → 17 → 91 → 3 → 68 → ...
```

После каждого выпавшего числа бот проверяет активные билеты.

Например:

```text
Билет игрока:

[12] [24] [37] [58] [91]

Выпало:

12
37
91

Осталось:

[24] [58]
```

Когда:

```text
remaining_numbers = []
```

билет считается закрытым и бот фиксирует победителя.

---

## 🏆 Победитель

Победитель определяется автоматически.

После выполнения условия победы бот:

1. фиксирует победивший билет;
2. определяет владельца билета;
3. завершает игру или текущий раунд;
4. отправляет сообщение в игровую группу.

Пример:

```text
🏆 ПОБЕДИТЕЛЬ!

Игрок: @username
Билет: #42

Все необходимые числа закрыты.

🎉 Поздравляем с победой!
```
